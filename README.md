# GlyphKeeper

**The campaign memory that stays true.** Your story. Our quest.

GlyphKeeper is a Discord co-pilot for human Dungeon Masters. It keeps characters, places, events, and summaries continuous across long campaigns—grounded in what actually happened at your table. Memory is the source of truth. The model never invents campaign canon. The human DM stays sovereign.

🌐 **[glyphkeeper.net](https://glyphkeeper.net)** · Waitlist open

---

## Hosted product (primary)

**Paid hosted GlyphKeeper** is the main product:

1. Create an account (Discord OAuth)
2. Subscribe
3. Invite the official GlyphKeeper bot to your Discord server(s)
4. Bind campaigns, run sessions, and use grounded co-pilot tools

You never create a Discord application, never run Node or Ollama yourself, and never manage infrastructure. One paid account can own multiple campaigns across multiple servers.

There is **no free tier** on the hosted product.

### What ships at public launch (H1 + H2)

**Core live co-pilot**

- Campaign binding to a Discord channel
- Session start / end
- Grounded answers on @mention (authoritative records + campaign-scoped semantic recall + light context only)
- Durable event extraction with importance/confidence filtering and name normalization
- Full memory toolkit (timeline, recall, edit, forget-with-preview, link/unlink characters & locations)
- Grounded session & campaign summaries (regeneratable from stored truth)
- Co-DM allowlist (owner controls who can mutate durable memory)

**Also at launch**

- Official always-on multi-tenant bot
- Minimal web dashboard (account, subscription, campaign list/create, usage meters, “invite the bot”)
- Web Memory UI (timeline + entity browser/editor)
- Session 0 structured intake (setting, tone, goals, bonds, open threads)
- DM Planning Session (pre-session co-planning grounded in party history and current state)
- Absent Player (opt-in/consent required, diegetic handling, light conservative vetoable control, actions tagged and reviewable)

**Philosophy**

- Memory is the source of truth — the model never invents campaign canon
- Co-pilot / continuity engine, never a replacement DM
- Human DM stays sovereign
- Continuity over pure simulation

## Local path (power users)

**glyphkeeper-local** is the secondary path: self-hosted bot + Ollama for people who want full control or offline inference.

- Free to run yourself
- Supported for power users and privacy-focused tables via [Patreon](https://www.patreon.com/glyphkeeper)
- Not the primary product story; setup and ops (host machine online during play, local models, your own Discord app) are on you

Local setup docs and releases are maintained for that audience. Prefer hosted unless you specifically need self-hosting.
