# GlyphKeeper

**A local-first AI co-pilot for human Dungeon Masters.**

GlyphKeeper lives in your Discord campaign channel and keeps the story continuous.  
It remembers NPCs, locations, plot threads, and session history so you can focus on running the table instead of digging through notes.

Built for real DMs who want grounded continuity — not a replacement for the human behind the screen.

🌐 **[glyphkeeper.net](https://glyphkeeper.net)**

---

## What it does

- Answers questions grounded in *your* campaign memory
- Tracks NPCs, locations, and important events
- Maintains session and campaign summaries
- Stays local-first (runs next to Ollama on your machine)
- Never invents canon — memory is the source of truth

---

## Status

Early public preview. Core co-pilot loop is live.  
More features (shared control, richer memory tools, planning aids) are in active development.
